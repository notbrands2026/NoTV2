# NoT v2.0 — Vercel-ready

A minimal Next.js ecommerce storefront scaffold configured for Vercel.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm start
```

## Deploy to Vercel
Import this repository into Vercel, or run:
```bash
npx vercel
npx vercel --prod
```

No secrets are required for this Stage 1 scaffold.
